## 📌 Executive Summary

**KaushalSetu Maharashtra** is a public-service digital platform designed for Maharashtra state that bridges the critical disconnect between vocational training providers, youth job seekers, and real-time industrial demand across Maharashtra's 36 districts.

Designed with an **official government digital-portal design language** (restrained navy/saffron palette, accessibility compliance, and high data density), it integrates **practical career progression** without cartoonish or juvenile aesthetics:
$$\text{Trust} \longrightarrow \text{Information} \longrightarrow \text{Action} \longrightarrow \text{Progress} \longrightarrow \text{Career Gamification}$$

---

## 🎯 The Maharashtra Challenge Addressed

1. **Regional Skill Mismatch**: Rapid growth in EV hubs (Pune, Chhatrapati Sambhajinagar), MIHAN Logistics (Nagpur), and Fintech (Mumbai) while local training institutes teach legacy curricula.
2. **Lack of Transparent Gap Diagnostics**: Students lack standardized tools to evaluate their readiness against MIDC hiring standards.
3. **Low Course Completion Rates**: Traditional e-learning suffers from learner fatigue; micro-challenges and milestone quests boost retention.
4. **Disjointed Job Placement**: Lack of direct verified telemetry connecting certified candidates with enterprise employers.

## 🚀 Key Platform Features & Modules

### 1. 🏛️ Official Government Portal Experience
- **Restrained Color Palette**: Deep Navy (`#0f172a`), Maharashtra Saffron (`#f59e0b`, `#d97706`), Charcoal, and Muted Emerald.
- **Top Utility & Accessibility Bar**:
  - Live Font Scaling (`A`, `A+`, `A++`)
  - High-Contrast Mode for low-vision accessibility
  - Trilingual Switcher (**English**, **मराठी**, **हिंदी**)
- **State Emblem Branding**: Clean abstract `MH-SETU` emblem badge and official digital service telemetry.

### 2. 🗺️ Maharashtra District Telemetry & Interactive Map
- Interactive vector map of Maharashtra featuring key industrial nodes:
  - **Pune**: Automotive & EV Powertrain Cluster (+180% surge)
  - **Mumbai & Thane**: BFSI, Cloud DevOps & Maritime Logistics
  - **Chhatrapati Sambhajinagar (AURIC / DMIC)**: Industrial Robotics, CNC & Auto Ancillaries
  - **Nagpur (MIHAN)**: Defense, Aerospace & Multi-Modal Logistics
  - **Nashik**: Electrical Power Equipment & Precision Agro-Export
  - **Kolhapur & Solapur**: Foundry Metallurgy, Bio-Refinery & Modernized Textiles
- Real-time telemetry displaying registered candidate pools, accredited PMKK/MSSDS hubs, and skill shortage indices.

### 3. 📋 Official Skill Gap Diagnostic & Certificate Generator
- Candidates select their **Target Job Role** (e.g. *Data Analyst*, *EV Powertrain Specialist*, *Robotics/CNC Specialist*, *Solar Smart Grid Tech*) and **Target Maharashtra District**.
- Input current competencies to generate an **Official Skill Gap Assessment Report**:
  - Unique Assessment ID (e.g. `MH-SKILL-894120`)
  - Readiness Gauge (%)
  - Identified Competency Gaps
  - Tailored Action Plan
  - **Print / PDF Export** compliant for offline government record keeping.

### 4. ⚡ Daily Skill Challenge (Micro-Learning)
- Government service-style daily task card with real-world scenarios (e.g. interpreting Maharashtra quarterly EV growth curves).
- Multiple-choice evaluation, immediate feedback, and XP/streak rewards.

### 5. 🗺️ Career Quest Roadmap
- Milestone roadmap replacing fantasy gaming with structured career engineering:
  - `FOUNDATION` $\rightarrow$ `CORE SKILLS` $\rightarrow$ `VISUALIZATION` $\rightarrow$ `PRACTICAL CAPSTONE` $\rightarrow$ `INTERNSHIP MATCHING`
- Milestone markers, competency criteria, and stage deep dive drawers.

### 6. 💼 Verified Industry Opportunity Portal
- Filterable jobs and apprenticeship openings with Tata AutoComp, Mahindra Mobility, SBI Digital Innovation Hub, and MIDC partners.
- **Responsive Tables**: Full-width data grid on desktop, automatically transforming into touch-friendly stacked cards on mobile devices.

## 💻 Quick Start & Demo Setup

### Prerequisites
- Node.js (v18+)
- npm or yarn

### 1. Clone & Install
```bash
git clone https://github.com/divyanshuuuuuuuuu/kaushalsetu-maharashtra-demo.git
cd kaushalsetu-maharashtra-demo
npm install
```

### 2. Run Demo Server
```bash
# Starts the server on port 8000
npm run dev
```

### 3. Open in Browser
- **Local Application:** [http://localhost:8000](http://localhost:8000)
- **Network Link:** `http://<your-ip>:8000`
