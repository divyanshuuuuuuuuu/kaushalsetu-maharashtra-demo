# KaushalSetu Maharashtra (कौशलसेतू महाराष्ट्र)
### Digital Skill Development & Industry Connect Platform

> A modern Maharashtra digital-service platform aligning state skill development programs with industry requirements, MIDC telemetry, and emerging job market demands.

---

## 🌟 Overview

**KaushalSetu Maharashtra** bridges the gap between student aspirations, accredited skill centers, and industry demand across all 36 districts of Maharashtra. Built with a modern government e-governance design system, it pairs career gamification with data telemetry.

### Key Capabilities:
- 🏛️ **Government Digital Service Interface**: Trustworthy, clean, official design language tailored with Maharashtra saffron and navy branding.
- 🌐 **Full Trilingual Localization**: Live toggle between English, Marathi (मराठी), and Hindi (हिंदी).
- ♿ **Inclusive Accessibility**: Real-time font size scaling (A-, A, A+) and high-contrast compliance mode.
- 🗺️ **Maharashtra District Telemetry & Map**: Interactive vector map tracking industry demand, candidate pools, and skill shortages across Pune, Mumbai, Thane, Nagpur, Nashik, Chhatrapati Sambhajinagar, Kolhapur, Solapur, etc.
- 🎯 **Official Skill Gap Diagnostic Tool**: Generates certified assessment reports (`MH-SKILL-XXXXXX`), readiness score gauge, missing competencies, and personalized action plans.
- 🏆 **Professional Progress & Micro-Challenges**: Daily skill challenges, career roadmaps (Data Analytics, EV Powertrain, Automation/CNC), milestone achievements, XP, and learning streaks.
- 💼 **Verified Opportunities Portal**: Job & apprenticeship matching connected directly with MIDC manufacturing, EV hubs, and tech clusters.

## 🚀 Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite 8
- **Styling**: Tailwind CSS + Custom Government Design Tokens
- **Icons**: Lucide React
- **Micro-Interactions**: Canvas-Confetti

## 💻 Local Setup & Development

```bash
# Clone the repository
git clone https://github.com/divyanshuuuuuuuuu/kaushalsetu-maharashtra.git

# Navigate to project directory
cd kaushalsetu-maharashtra

# Install dependencies
npm install

# Run the development server (configured on port 8000)
npm run dev

# Build for production
npm run build
```
